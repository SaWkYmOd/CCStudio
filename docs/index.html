CC Studio is a free Windows app for the Elegoo Centauri Carbon running OpenCentauri. Design your own boot animation and logo, recolour the whole touchscreen interface in any colour, and put everything back to stock with one click.

How it works

No flashing, no firmware swaps. CC Studio talks to your printer over SSH, uploads your files to the places the screen reads them from, and reboots it. Everything stock stays safely in the printer's read-only layer, so it can always be restored.

01

Connect

Enter your printer's IP address in Settings (the password is OpenCentauri's default) and press Test connection. If anything is off, Fix sorts it.

02

Design

Make a boot animation, pick a boot logo, or choose a theme colour. Every tab shows a live preview before anything touches the printer.

03

Install

Press Install now. CC Studio uploads, checks and (optionally) reboots your printer. Don't like it? The Restore tab undoes it all.

Restore

One click back to stock

Tick what you want back and press Restore. Each item is compared with the printer's untouched stock copy, so it only changes what you actually changed.

  • Animation and all icons
  • Screen layout
  • Screen program (if the advanced option was used)
  • Boot logo
  • Optional reboot afterwards

Built to be safe

CC Studio never flashes firmware. Stock files live in the printer's read-only layer and your changes sit on top, so removing them returns the stock file. The printer's SSH service runs separately from the touchscreen, so even if a change looks wrong on screen you can still connect and restore it. The risky advanced screen-program patch is off by default and checks the file's fingerprint first, skipping itself if it isn't the exact stock version.

Questions

Quick answers.

Which printer does it work with?

The Elegoo Centauri Carbon running OpenCentauri firmware.

Does it work on my firmware version, and without a Canvas unit?

CC Studio was built and tested on one Centauri Carbon running OpenCentauri. The Canvas page is part of the printer's own screen files, so it is recoloured whether or not you have a Canvas unit. The screen layout and screen program recolours only apply when the printer's file exactly matches the stock version they were made for; on a different firmware version those parts are skipped safely. The icon recolour, boot animation, boot logo and Restore tab don't depend on that, so you may get a partial recolour on other versions.

Does it work on Mac or Linux?

The download is a Windows app (Windows 10/11).

Do I need to install anything?

No. Unzip the folder and run CC Studio.exe. Your PC and the printer just need to be on the same network.

Can I undo everything?

Yes. Open the Restore tab, tick what you want back and press Restore.

Is it free?

Yes. It is a community project, not affiliated with Elegoo or OpenCentauri. Use at your own risk.
